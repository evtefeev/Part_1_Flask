5 простих Flask проєктів

1. URL Shortener (міні bit.ly)
- Скорочення довгих URL
- Генерація короткого коду
- Редірект на оригінальне посилання
Навички: маршрутизація, redirect, збереження даних

2. ToDo список
- Додавання задач
- Видалення задач
- Позначення як виконаних
Навички: Jinja2, простий CRUD, форми HTML

3. Погода через API
- Введення міста
- Отримання погоди через OpenWeather API
- Відображення температури та стану
Навички: requests, JSON, API інтеграція

4. Генератор паролів
- Вибір довжини
- Символи / цифри / uppercase
- Генерація пароля
Навички: логіка Python, простий UI

5. Міні нотатки (Notes App)
- Додавання нотаток
- Перегляд списку
- Видалення нотаток
Навички: CRUD, SQLite або JSON, форми Flask
